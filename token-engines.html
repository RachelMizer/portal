🌋 Why Excessive Token Engines Are Banned in Portal

Excessive Token Engines

Core Reason

Heavy token engines are banned because they overwhelm the slot system and make the Creator Slot/token-shift mechanic unmanageable.

Design Philosophy

Portal allows:

  • Some token-creator creatures.
  • Simple tokens (1/1, 2/2, temporary).
  • Tokens tied to their parent's slot.

Mass token engines:

  • Flood the board with tokens.
  • Make tracking parent/slot relationships difficult.
  • Turn the game into "token math" instead of Portal's core loop.

Gameplay Problems

  • Board clutter — too many bodies to track.
  • Slot overload — Creator Slot interactions become unclear.
  • Balance issues — token engines dominate combat.

Practical Rule

Cards that create large numbers of tokens repeatedly or scale massively with game state are banned or heavily restricted in Portal.
